# Видео для утренней рассылки

Папка-приёмник для коротких видеофайлов. Бот при отправке выбирает из неё
**случайный** файл (без повторов за последние N) — см. задачу T-14 в
[.agents/TASKS.md](../../../.agents/TASKS.md).

**Сюда можно просто накидывать файлы** — перезапускать бота и регистрировать
их вручную не нужно: список сканируется при старте и пополняется по мере
появления новых файлов.

## Требования к файлу

| Параметр | Значение |
|---|---|
| Формат | `.mp4` (H.264 + AAC), реже `.mov`, `.webm` |
| Разрешение | до 1280×720 |
| Длительность | до 30 секунд |
| Размер | желательно до 10 МБ (точную границу TDM уточнить) |
| Имя | любое, на отбор не влияет; лучше `NN_описание.mp4` для порядка |

## ⚠️ Важно: превью генерируется через OpenCV

`send_video` в SDK (`util.py:101-132`) сам берёт кадр из файла и загружает
превью через `cv2`. Если в контейнере нет `libgl1-mesa-glx` — отправка упадёт
с ошибкой, даже если сам файл в порядке. В [Dockerfile](../../Dockerfile:4-7)
библиотека уже ставится, но **проверить на стенде надо до написания T-14**.

Если превью не генерируется, есть запасной путь: отправить файл как вложение
через `send_file` вместо `send_video` — тогда OpenCV не нужен, но вместо видеоплеера
пользователь увидит иконку файла.

## Каталог `gif/`

Соседняя папка `../gif/` — это **наследие Telegram-версии** (`batut.mp4`,
`robot_y4it.mp4`). В рассылку не попадает. Можно перенести нужные файлы сюда
и удалить папку, когда будет решён вопрос с содержимым.
